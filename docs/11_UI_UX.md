# 11. User Interface and Experience

## Navigation

Primary sections:

1. Search
2. Drives
3. People
4. Review
5. Scan activity
6. Archive health
7. Settings

## Search screen

### Main elements

- natural-language search field
- recent searches
- filter panel
- thumbnail grid
- sort by relevance, date, drive or filename

### Result card

Show:

- thumbnail
- drive number badge
- online or offline indicator
- filename
- likely date or range
- matched person or concept tags

## Drive library

Each drive card shows:

- **Drive 14**
- friendly name
- capacity and used-space snapshot
- online or offline status
- last scan
- change status
- main categories
- image count
- physical storage location
- backup relationship when available

## Drive detail

- identity and manifest status
- approved roots and exclusions
- scan and verification controls
- content summary
- common concepts
- people found
- date distribution
- failures and unreadable files
- catalogue history

## Image detail

- larger cached preview
- exact source path
- drive number and connection state
- metadata
- automatic scene description
- user tags
- face labels
- date evidence
- duplicate and similarity links
- Reveal in Finder when connected

If offline, replace opening actions with a clear instruction such as:

> Connect Drive 14 to open the original.

## People screen

- named people
- aliases and optional relationship
- confirmed image count
- possible matches needing review
- unknown recurring faces

## Review queues

Separate queues for:

- unknown people
- uncertain face matches
- date suggestions
- duplicate candidates
- failed files
- drive identity conflicts

## Scan experience

Show meaningful progress without encouraging unsafe interruption:

- files discovered
- files complete
- current stage
- throughput
- estimated remaining work only when based on stable data
- failed count
- verifier status

Closing the window must not corrupt work. The user can pause safely at a batch boundary.

## Accessibility

- clear, plain language
- keyboard navigation
- scalable text
- high contrast
- avoid relying on colour alone
- generous spacing
- clear error recovery instructions
