# 14. Roadmap

## Phase 0: repository and safety foundation

- Tauri and React scaffold
- Rust service boundary
- SQLite migration framework
- structured logging
- application support paths
- source-integrity test fixture
- coding-agent loop installed

## Phase 1: drive registration

- drive table and UI
- physical numbering
- identity manifest
- volume event detection
- conflict handling
- online and offline states

## Phase 2: safe scanner and queue

- approved roots
- traversal safety
- durable queue database
- batch leases
- interruption and resume
- progress JSON and JSONL log
- disk-space checks

## Phase 3: base image indexing

- image decoding
- thumbnail generation
- EXIF extraction
- perceptual hash
- catalogue commits
- real verifier
- offline thumbnail browsing

## Phase 4: catalogue search

- filename, path and metadata search
- drive filters
- user tags
- connected or offline filters
- image detail view

## Phase 5: visual intelligence

- local image embeddings
- local query embeddings
- vector search
- broad concept tags
- similar-image search
- model versioning

## Phase 6: family faces

- face detection
- encrypted face embeddings
- clustering
- human review queue
- people and aliases
- merge and split tools
- rebuild-faces command

## Phase 7: dates and scans

- capture-date candidate model
- scanned-print detection
- date-range estimator
- evidence display
- human date correction

## Phase 8: hardening

- malformed-file isolation
- crash recovery
- migration recovery
- large-library performance
- accessibility pass
- redacted diagnostics
- packaging and clean install tests

## Phase 9: archive health

- duplicate review
- missing and changed files
- full validation scans
- optional backup relationships
- integration with a future Backup Verifier module

## Priority rule

Complete safety, queue durability and verifier behaviour before expanding AI capability. A smaller trustworthy indexer is more valuable than a feature-rich unsafe one.
